AUTOVID-SHORTS — INSTALLER ET LANCER SUR VOTRE PC (WINDOWS)
==========================================================

Dans l'invite de commandes (touche Windows, cmd, Entrée) :

  cd %USERPROFILE%\Desktop
  curl -L -o INSTALLER-autovid-shorts.bat https://raw.githubusercontent.com/YoutubeVieira/autovid-shorts/main/INSTALLER.bat
  INSTALLER-autovid-shorts.bat

Dépôt privé : si curl télécharge une page d'erreur (404), ouvrez
https://github.com/YoutubeVieira/autovid-shorts/blob/main/INSTALLER.bat connecté à GitHub,
bouton « Download raw file », puis double-cliquez sur le fichier.

ÉTAPES
1. Outils : vérifie Git, Python, Node.js, FFmpeg et Claude Code ; propose d'installer ce qui manque
   (après une installation : fermez la fenêtre et relancez le fichier).
2. Projet : le télécharge dans Documents\autovid-shorts (ou le met à jour). Dépôt privé : connectez-vous
   à GitHub avec le compte YoutubeVieira si une fenêtre le demande.
3. Installation :
   - le modèle de montage Remotion (npm install, environ 1 minute) ;
   - earshot (effets sonores) et les 7 styles de création MP4 (environ 200 Mo), si vous acceptez ;
   - la transcription (faster-whisper) pour la super-analyse ;
   puis il propose d'ANALYSER UNE VIDÉO : glissez-la dans la fenêtre, Entrée.
   Résultats dans analyses\<nom>\ : super.md, secondes.md, prompts.md (sans image).
4. Session Claude : lance « claude remote-control ». Laissez la fenêtre OUVERTE et ouvrez
   l'application Claude Code : la session « autovid-shorts » apparaît. Exemples de demandes :
     - « lance la machine pour la semaine prochaine »
     - « fais une pub claymation de 20 s pour … »
     - « super-analyse de C:\Users\…\ma_video.mp4 »

ANTIGRAVITY : ouvrez le dossier Documents\autovid-shorts ; workflows dans .agent\workflows\.

EN CAS D'ERREUR : copiez le message affiché et envoyez-le à Claude.
