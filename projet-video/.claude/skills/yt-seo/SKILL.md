# /yt-seo

1. **Mot-clé principal** : la formulation que la cible tape (vérifie avec les suggestions de recherche YouTube si l'accès web existe). Il apparaît dans le titre (3 premiers mots si possible), la 1re phrase de la description et le 1er chapitre.
2. **Description** :
   - 2 premières lignes (visibles sans « plus ») = promesse + mot-clé.
   - Liens / ressources.
   - Chapitres de `/yt-chapters`.
   - 3 hashtags max, le plus important en premier.
3. **Tags** : 5 à 10, du plus précis au plus large ; le nom de la chaîne en dernier.

Sortie : bloc description prêt à coller + liste de tags séparés par des virgules.
