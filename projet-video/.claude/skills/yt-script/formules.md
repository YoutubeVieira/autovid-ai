# 21 formules de hook

| # | Nom | Gabarit | Exemple |
|---|-----|---------|---------|
| 1 | Le Reçu | « J'ai [résultat chiffré] en [durée]. Voilà comment. » | « 100 000 vues en 9 jours avec une seule skill. » |
| 2 | L'Initié | « Ce que [experts] ne disent jamais sur [sujet]. » | « Ce que les monteurs ne te diront jamais sur les coupes. » |
| 3 | La Promesse impossible | « [Chose difficile] sans [effort attendu]. » | « Une app complète sans écrire une ligne de code. » |
| 4 | La Comparaison | « [A] vs [B] : le gagnant m'a surpris. » | « Claude vs un monteur pro sur la même vidéo. » |
| 5 | L'Origine | « Comment [chose connue] a vraiment commencé. » | |
| 6 | La Date limite | « Dans [délai], [changement] — prépare-toi. » | |
| 7 | L'Adresse directe | « Si tu [situation précise], cette vidéo est pour toi. » | « Si tu publies sans plan, arrête. » |
| 8 | Le Résultat d'un autre | « [Personne] a fait [résultat] avec [méthode]. » | |
| 9 | L'Erreur | « L'erreur qui tue [objectif] (tout le monde la fait). » | |
| 10 | Le Retournement | « Tout le monde dit [croyance]. C'est faux. » | |
| 11 | La Révélation | « Je n'aurais jamais dû montrer ça. » | |
| 12 | Le Superlatif | « Le [outil] le plus [adjectif] de [année]. » | « La skill la plus absurde de 2026. » |
| 13 | L'Horloge | « En [N] secondes, tu vas savoir [chose]. » | |
| 14 | J'ai testé | « J'ai testé [chose] pendant [durée]. » | |
| 15 | La Question | « Pourquoi [phénomène étrange] ? » | |
| 16 | La Liste | « [N] [choses] qui [bénéfice]. » | « 11 skills qui font tourner ta chaîne. » |
| 17 | Le Démontage | « J'ai démonté [succès] pièce par pièce. » | |
| 18 | La Stack | « Tout ce que j'utilise pour [résultat]. » | |
| 19 | L'Annonce de mort | « [Outil/acteur] vient de tuer [marché]. » | « Claude vient de tuer le YouTube. » |
| 20 | L'Avant/Après | « Avant : [douleur]. Après : [résultat]. » | |
| 21 | Le Secret partagé | « Personne n'en parle, mais [fait]. » | |

Règles : le hook tient en une phrase lisible en < 3 s ; il contient soit un chiffre, soit un nom concret, soit une contradiction.
