AUTOVID-SENIOR — INSTALLER ET LANCER SUR VOTRE PC (WINDOWS)
==========================================================

Dans l'invite de commandes (touche Windows, cmd, Entrée) :

  cd %USERPROFILE%\Desktop
  curl -L -o INSTALLER-autovid-senior.bat https://raw.githubusercontent.com/YoutubeVieira/autovid-senior/main/INSTALLER.bat
  INSTALLER-autovid-senior.bat

Dépôt privé : si curl télécharge une page d'erreur (404), ouvrez
https://github.com/YoutubeVieira/autovid-senior/blob/main/INSTALLER.bat connecté à GitHub,
bouton « Download raw file », puis double-cliquez sur le fichier.

ÉTAPES
1. Outils : vérifie Git, Python, FFmpeg et Claude Code ; propose d'installer ce qui manque
   (après une installation : fermez la fenêtre et relancez le fichier).
2. Projet : le télécharge dans Documents\autovid-senior (ou le met à jour). Dépôt privé : connectez-vous
   à GitHub avec le compte YoutubeVieira si une fenêtre le demande.
3. Installation :
   - les dépendances Python (numpy, Pillow) ;
   - earshot (effets sonores), si vous acceptez ;
   puis il vérifie la séance d'exemple de 50 secondes.
4. Session Claude : lance « claude remote-control ». Laissez la fenêtre OUVERTE et ouvrez
   l'application Claude Code : la session « autovid-senior » apparaît. Exemples de demandes :
     - « monte l'exemple de 50 secondes avec mes fichiers »
     - « crée une séance d'équilibre de 10 minutes »

ANTIGRAVITY : ouvrez le dossier Documents\autovid-senior ; workflows dans .agent\workflows\.

EN CAS D'ERREUR : copiez le message affiché et envoyez-le à Claude.
