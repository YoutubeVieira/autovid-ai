# /replica-brand — en faire ton produit

1. **Nom** : 10 propositions (courtes, prononçables, sans ressemblance avec la marque originale) ; vérifie la disponibilité du .com/.app si la recherche web est possible. L'utilisateur choisit.
2. **Promesse** : une phrase qui répond aux 3 premiers problèmes de `reviews.md` (« L'agenda qui ne se trompe jamais de fuseau, à prix fixe »).
3. **Logo** : monogramme SVG simple dans `public/logo.svg` (couleur d'accent de `/replica-design`).
4. **Landing** (`app/(marketing)/page.tsx`) : hero (promesse + CTA), 3 problèmes → 3 solutions (avec les citations d'avis, sans nommer l'original si l'utilisateur préfère), prix, FAQ, CTA final. Balises meta, OpenGraph, sitemap.
5. **Ton** : 5 règles d'écriture dans `replica/brand.md`.
