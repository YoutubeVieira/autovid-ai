Suis la skill `sfx-pack`. Un son par action visible, jamais en continu: `ding` pour +1 habitant, `coin` pour emploi, `tick` pour le compteur, `whoosh` pour une coupe, `level_up` pour un palier, `stamp` pour le carton de fin. Les bruitages restent sous la voix (gain 0,55). Pour un son qui manque, ajoute-le dans `packs/sfx/make_sfx.py` (synthese, donc CC0) plutot que d'importer un echantillon de licence inconnue.
