# Skills

Six skills, chacune dans son dossier (un `SKILL.md`, et des `scripts/` quand il y en a). Pour les importer dans Claude : Réglages > Capacités > Skills > importer le .zip de la skill (les .zip se refont avec `python -m zipfile -c zip/<nom>.zip <nom>/`).

| Skill | Rôle |
|---|---|
| voix-chirp-antigravity | Produire les voix Google Chirp 3 HD sur votre PC (le script `voix_chirp.py` dont elle parle n'est pas dans ce dossier) |
| animation-synchro-voix | Caler bouche, regard, gestes et respiration des personnages sur la voix |
| futur-moi-visualisation | Écrire les scripts audio de visualisation Futur Moi, prêts pour la voix |
| montage-youtube-stock | Vidéo YouTube 16:9 : voix off, clips Pexels/Pixabay, sous-titres, chapitres |
| motion-design-video | Vidéo en motion design codée : personnage animé, explications, musique |
| sound-design-auto | Sound design : whoosh, pops, ticks placés sur l'image, puis mixage |
